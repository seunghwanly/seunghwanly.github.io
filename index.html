  3. 2022.08 첫 앱 출시. Databank에서 TOEFL 학습 서비스 TestGlider의 첫 iOS·Android 앱을 출시하고, 같은 달 모바일 파트를 맡았습니다.
  4. 2023.04 첫 GetX → Bloc. GetX로 짜인 TestGlider 앱을 2023년 4월부터 두 달 동안 Bloc으로 옮겼습니다. 같은 전환을 윙크 앱에서 한 번 더 하게 됩니다.
  5. 2023.09 타입부터 선언. PPB Studios에서 맡은 윙크 앱에는 타입 선언이 없었습니다. 함수의 인자와 반환 타입을 코드 전체에 적어, 실행해야 보이던 오류를 코드에서 보이게 했고, 구독이 쌓이던 Event Bus도 걷어내기 시작했습니다.
  6. 2024.02 두 번째 GetX → Bloc. 윙크 앱도 멤버십부터 Bloc을 들이고 2024년 7월 GetX를 걷어냈습니다. 서비스를 멈추지 않고 화면 단위로 옮겼습니다.
  7. 2024.06 규칙을 코드에. lint 규칙을 켜 새로 들어오는 코드가 자동으로 검사받게 했습니다. 이후 반복되는 실수는 custom_lint 규칙으로 막고, 테스트를 700개 넘게 쌓았습니다.
  8. 2025.06 오픈소스 패키지와 프리랜스 앱. Kakao Maps SDK v2를 Flutter에서 쓸 수 있게 kakao_maps_flutter 패키지를 만들어 pub.dev에 배포했습니다. 이어서 프리랜서로 한일 교류 SNS 우리다치의 Flutter 앱을 맡아 WebSocket 채팅에 AI 번역을 붙였습니다.
  9. 2025.11 앱 코드로 웹을 열다. 예약이 되지 않던 Vue2 웹을 고치는 대신, 이미 검증된 Flutter 앱을 웹으로 확장해 기한보다 한 달 앞서 열었습니다.
  10. 2026.03 볼 수 있는 웹으로. Flutter Web으로 연 통합멤버십은 Canvas라 계측이 되지 않았습니다. DOM으로 두 번 옮겨 Vite React에 정착하고 나서야 이탈 구간이 보였습니다.
  11. 2026.07 앱 안의 React. 4개 브랜드의 예약 상세를 React 앱 하나로 합치고, Flutter 앱은 WebView로 그 화면을 엽니다. 이제 앱 심사 없이 고칩니다.
